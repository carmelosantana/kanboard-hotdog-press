# Provenance of bundled files

Everything the editor loads is a file in this plugin; nothing is fetched from another origin.

`06bfe0d62a98375cb09c942fa18e68bd32cff057` (branch `main`). Each family's `OFL.txt` was read and is the SIL Open Font
License, Version 1.1; it ships beside the font. The files are the repository's TrueType files, unmodified (the
